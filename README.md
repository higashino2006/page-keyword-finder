# Page Keyword Finder - Chrome拡張機能

URLのpage=パラメータを自動的にカウントアップしながら、指定したキーワードを検索するChrome拡張機能です。

## 機能

- 現在のURLからpage=パラメータを検出
- 指定した最大ページ数まで自動的にページ遷移
- 各ページでキーワードを検索
- キーワードが見つかったらその場で停止
- 見つかったキーワードを黄色でハイライト表示
- Cookie・ログイン状態を維持したまま検索

## インストール方法

1. Chromeを開く
2. アドレスバーに `chrome://extensions/` と入力
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. このフォルダ（page-keyword-finder）を選択

## 使い方

1. 検索したいページ（page=パラメータを含むURL）を開く
   - 例: `https://example.com/search?page=1&query=test`
   - page=パラメータがない場合は自動的に追加されます

2. ブラウザのツールバーにある拡張機能アイコンをクリック

3. ポップアップで以下を入力：
   - **検索キーワード**: 探したい文字列
   - **最大ページ数**: 何ページまで検索するか（デフォルト: 50）

4. 「検索開始」ボタンをクリック

5. 拡張機能が自動的に：
   - 現在のページでキーワードを検索
   - 見つからなければ次のページ（page=2, 3, 4...）へ自動遷移
   - キーワードが見つかったらその場で停止してアラート表示

6. 検索を途中で止めたい場合は、拡張機能アイコンをクリックして「検索停止」ボタンを押す

## 注意事項

- ページ遷移を伴うため、検索中はブラウザを他の用途に使えません
- ログインが必要なサイトでも、既存のログイン状態を維持したまま検索できます
- 検索速度はページの読み込み速度に依存します
- 無限ループを防ぐため、最大ページ数を適切に設定してください

## トラブルシューティング

### URLにpage=パラメータが見つからない
- 対象のサイトがpage=以外のパラメータ（例: p=, offset=）を使っている場合、この拡張機能は動作しません
- content.jsのgetNextPageUrl()関数をカスタマイズすることで対応可能です

### 検索が止まらない
- 「検索停止」ボタンを押してください
- それでも止まらない場合は、ページを手動でリロードしてください

### キーワードが見つからない
- 大文字小文字を正確に入力してください（現在は完全一致検索）
- ページが完全に読み込まれる前に検索している可能性があります

## カスタマイズ

### 他のパラメータ名に対応したい場合

content.jsの`getNextPageUrl()`関数を編集：

```javascript
// 例: "p="パラメータに対応
if (params.has('p')) {
  const currentPage = parseInt(params.get('p')) || 0;
  params.set('p', currentPage + 1);
  return currentUrl.toString();
}
```

### 大文字小文字を区別しない検索にしたい場合

content.jsの`checkCurrentPage()`関数を編集：

```javascript
// 変更前
const found = pageText.includes(keyword);

// 変更後（大文字小文字を無視）
const found = pageText.toLowerCase().includes(keyword.toLowerCase());
```
